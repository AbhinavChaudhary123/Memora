# MEMORA — MERN Edition

A redesigned nostalgic social-memory platform built with MongoDB, Express, React and Node.js. The original visual palette is intentionally preserved: warm `#FAFAD2`, charcoal `#2C2C2C`, muted grays and the original blue `#4A90E2` accent.

## Features
- Secure JWT authentication with bcrypt password hashing
- Stories with tags, mood, likes, comments, bookmarks and editing
- Personal diary / saved memories
- Places with city/state, visit season and memorable notes
- Global search across stories, users and places
- Profile pages with stats and activity
- Memory timeline and dashboard
- Responsive nostalgic UI with glass/paper cards and subtle motion
- Protected API routes and ownership checks
- Seed script with demo data

## Run
1. Create `server/.env` from `.env.example`.
2. `npm install`
3. `npm run install-all`
4. `npm run dev`

Client: http://localhost:5173
API: http://localhost:5000
